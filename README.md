# Retail Sales Dashboard

## Project Overview
Built an interactive Power BI dashboard to analyze retail sales data.

## Tools Used
- Power BI
- Excel

## What I Did
- Analyzed 9,970 rows of Superstore data
- Created 4 KPI cards (Sales, Profit, Quantity, Discount)
- Built bar charts, pie chart, and slicer
- Added interactive filters

## Key Insights
- Total Sales: 2.30M
- Total Profit: 286.40K
- Total Quantity: 38K
- Average Discount: 0.16
- Technology is top category
- West region has highest sales
